# Estrategia SEO de WiseLife

## Propósito

Esta carpeta define la estrategia SEO desde el lanzamiento de WiseLife: adquisición orgánica cualificada, confianza para servicios de salud mental y una base técnica medible. El documento debe aplicarse sin exponer información clínica, perfiles privados ni rutas autenticadas.

## Objetivos del lanzamiento

- Lograr que la página pública principal sea rastreable, indexable y entendible en español colombiano.
- Capturar búsquedas de alta intención relacionadas con psicología clínica, terapia psicológica y bienestar emocional en Bogotá y modalidad online.
- Construir señales de confianza con contenido útil, autores identificables, políticas claras y datos estructurados válidos.
- Mantener una experiencia rápida, estable y accesible en móvil.

## Principios

1. **Privacidad primero:** nunca indexar dashboards, citas, onboarding, autenticación o datos de pacientes.
2. **Intención antes que volumen:** priorizar consultas con necesidad explícita de ayuda y contexto local.
3. **Evidencia y confianza:** toda afirmación clínica debe revisarse por un profesional; evitar promesas de resultados.
4. **Una URL, una intención:** evitar duplicados por parámetros, filtros o estados de sesión.
5. **Medir antes de escalar:** no aumentar contenido o enlaces sin observar conversiones cualificadas y calidad técnica.

## Definiciones de lanzamiento

- **Dominio canónico:** `VITE_SITE_URL`, sin barra final.
- **Idioma principal:** `es-CO`; usar `lang="es"` y copy localizado.
- **Superficie indexable inicial:** únicamente la página pública principal hasta que cada nueva ruta tenga contenido único, revisión legal/clínica y una decisión explícita de indexación.
- **Conversión primaria:** solicitud de orientación o inicio del flujo público definido por producto.
- **Conversión secundaria:** interacción con CTA, navegación a información de servicios y contacto.

## Criterio de éxito

SEO estará listo para lanzamiento cuando la URL canónica, robots, sitemap, metadatos, datos estructurados, privacidad de rutas y medición estén validados en producción, y cuando las métricas de campo no muestren regresiones de LCP, INP o CLS.
